⚠️ Belum Terhubung ke Database

Aplikasi ini butuh Firebase Database URL supaya data absen bisa tersimpan & sinkron di semua HP.

Caranya:
1. Buka file index.html ini dengan editor teks (Notepad / GitHub).
2. Cari baris const FIREBASE_DB_URL = "TEMPEL_DATABASE_URL_FIREBASE_DI_SINI";
3. Ganti bagian dalam tanda kutip dengan Database URL dari Firebase Anda.
4. Simpan & upload ulang ke GitHub.

Lihat Tutorial_GitHub_Firebase.md untuk panduan lengkap bergambar.
